>Examine a palavra.

Site de estudo bíblico com foco no contexto histórico de cada livro. Cada livro tem ficha de contexto, explicação capítulo a capítulo com versículos, fontes para consulta, etapas de estudo, anotações e questionário. Um painel mostra o progresso de estudo.

O nome vem de Atos 17:11, que elogia os moradores de Beréia por examinarem as Escrituras todos os dias.

Projeto individual de Análise e Desenvolvimento de Sistemas (SPTech, turma 1ADSA).

## Livros incluídos

Gênesis, Êxodo, Daniel, Mateus, Marcos, Lucas, João, Atos, Romanos e Apocalipse.

## Tecnologias

- HTML e CSS inline
- JavaScript puro
- Fontes Lora e Nunito (Google Fonts)

## Como rodar

1. Baixe ou clone o repositório.
2. Mantenha na mesma pasta o `index.html`, a imagem `iniciositejpg.jpg` e o logo `Bereia (1).png`.
3. Abra o `index.html` no navegador (ou use a extensão Live Server do VS Code).
4. Crie uma conta e comece a estudar.

## Fontes do conteúdo

O contexto histórico foi preenchido a partir de fontes de consulta, que aparecem em cada livro com referência em ABNT:

- Encyclopaedia Britannica (artigos sobre cada livro e sobre a literatura bíblica)
- Bible Odyssey, da Society of Biblical Literature
- The Gospel Coalition (comentário de Daniel)
- TheTorah.com (artigo sobre Antíoco IV e o livro de Daniel)
- The New Oxford Annotated Bible (capítulo de Êxodo)

Os textos de "Capítulo a capítulo" são um resumo de apoio e devem ser conferidos com uma Bíblia e com as fontes acima.
