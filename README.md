# Bereia

O **Bereia** é um site de estudo bíblico desenvolvido com o objetivo de aprofundar a compreensão das Escrituras por meio do contexto histórico, político, religioso e geográfico de cada livro.

A plataforma reúne informações históricas, explicações capítulo a capítulo, referências bíblicas e fontes para consulta, oferecendo um ambiente organizado para acompanhar o estudo da Palavra.

O acesso às ferramentas de estudo é realizado mediante cadastro e login. Após entrar na plataforma, o usuário pode consultar os livros disponíveis, registrar suas etapas de estudo, fazer anotações, responder questionários e acompanhar seu desenvolvimento por meio de uma dashboard.

O nome Bereia tem origem em Atos 17:11, passagem que destaca os moradores de Beréia por examinarem diariamente as Escrituras para verificar aquilo que ouviam.

## Funcionalidades

### Área pública
- Página inicial com apresentação do projeto.
- Origem e propósito do Bereia.
- Explicação sobre o significado do nome.
- Apresentação da organização da Bíblia.

### Área do usuário
Disponível após cadastro e login.

- **Biblioteca bíblica:** acesso aos nove livros selecionados.
- **Ficha de contexto:** autor, destinatários, data, local, cenário político e religioso e contexto histórico.
- **Capítulo a capítulo:** explicações de cada capítulo, acompanhadas de referências bíblicas.
- **Conexões bíblicas:** referências a outras passagens que complementam a compreensão do conteúdo.
- **Etapas de estudo:** organização e acompanhamento das etapas de leitura.
- **Questionários:** atividades para revisar e fixar o conteúdo estudado.
- **Dashboard:** painel visual com indicadores de progresso, capítulos concluídos, questionários respondidos e desempenho nas atividades.

## Tecnologias utilizadas

- HTML5 — estrutura das páginas.
- CSS3 — estilização e identidade visual.
- JavaScript — interatividade e funcionalidades.
- MySQL — armazenamento e gerenciamento dos dados.
- Linux (VM) — ambiente de hospedagem do banco de dados e da aplicação de cálculos matemáticos.

## Arquitetura do projeto

O Bereia é organizado em três componentes principais:

1. **Front-end:** interface desenvolvida em HTML, CSS e JavaScript, responsável pela interação com o usuário.
2. **Banco de dados:** MySQL, responsável por armazenar informações dos livros, usuários, registros de estudo e respostas dos questionários.
3. **Infraestrutura:** máquina virtual Linux, utilizada para hospedar o banco de dados e a aplicação de cálculos matemáticos.

## Como rodar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se os arquivos de imagem estão nos diretórios indicados no código.
4. Inicie o projeto pelo arquivo `index.html` ou utilize a extensão Live Server.
5. Para utilizar as funcionalidades integradas ao banco de dados, configure a conexão com o MySQL e a máquina virtual Linux.
6. Acesse a plataforma, realize seu cadastro e faça login para entrar na área de estudos.

**Observação:** a abertura direta do HTML permite visualizar a interface, mas as funcionalidades que dependem do banco de dados precisam da infraestrutura correspondente em execução.

## Fontes do conteúdo

O conteúdo histórico foi elaborado com base em fontes de consulta, indicadas nas respectivas seções dos livros e referenciadas conforme as normas ABNT.

Entre as fontes utilizadas estão:

- Encyclopaedia Britannica — artigos sobre os livros bíblicos e a literatura bíblica.
- Bible Odyssey — publicação da Society of Biblical Literature.
- The Gospel Coalition — materiais de estudo e comentários bíblicos.
- TheTorah.com — estudos e artigos sobre o contexto histórico do Antigo Testamento.
- The New Oxford Annotated Bible — material de referência para o estudo bíblico.

Os textos da seção capítulo a capítulo são resumos de apoio ao estudo e não substituem a leitura da Bíblia. Recomenda-se consultar as passagens bíblicas e as referências indicadas para aprofundar a compreensão.
